# 🧡 SRH Analytics Dashboard

A professional-grade IPL analytics dashboard for Sunrisers Hyderabad, built with Python, Plotly, and Streamlit.

🔗 **Live Demo:** https://spoorthy-srh-dashboard.streamlit.app

---

## 📌 About the Project

This dashboard provides a comprehensive data-driven analysis of Sunrisers Hyderabad's IPL journey from 2013 to 2026 — covering season performance, batting and bowling analytics, venue insights, and an All Time XI selection.

Built as a Data Visualization Techniques (DVT) project and portfolio piece, combining real cricket data with professional-level UI design.

---

## 📊 Dashboard Features

**Tab 1 — Season Overview**
- Win/Loss breakdown by season (2013–2026)
- Win percentage trend line
- Performance by venue heatmap
- Fortress & nightmare venue cards

**Tab 2 — Batting Analysis**
- Top 10 SRH run scorers
- Legend comparison radar chart (Warner, Abhishek, Dhawan, Head, Williamson, Klaasen)
- Runs vs Strike Rate scatter plot
- Detailed batting stats table

**Tab 3 — Bowling Analysis**
- Top 10 SRH wicket takers
- Bowling legend stat cards (Bhuvi, Rashid, Steyn, Natarajan, Cummins)
- Economy vs Wickets scatter plot
- Detailed bowling stats table

**Tab 4 — Player Spotlight**
- SRH All Time XI cricket field visual
- Individual player stat cards for all 11 players
- Honorary mention: BCJ Cutting — 2016 Final Hero 🧡

---

## 🔍 Key Insights

- **2016 was SRH's best season** — 64.7% win rate, IPL Champions 🏆
- **2021 and 2023 were the dark years** — only 28.6% win rate
- **Rajiv Gandhi Stadium is SRH's fortress** — 61.2% win rate from 67 matches
- **Wankhede is SRH's nightmare** — only 26.7% win rate
- **David Warner is SRH's all-time leading run scorer** — 4138 runs, SR 141.7
- **Abhishek Sharma is the future** — SR of 169.6, already 2 centuries

## 🛠️ Tech Stack

- **Python** — core language
- **Pandas & NumPy** — data cleaning and manipulation
- **Plotly** — interactive visualizations
- **Streamlit** — dashboard framework and deployment

---

## 📁 Dataset

Data sourced from Kaggle IPL dataset covering ball-by-ball data from 2008–2026.
- `ball_by_ball_data.csv` — every delivery bowled
- `ipl_matches_data.csv` — match results and details
- `players-data-updated.csv` — player profiles
- `teams_data.csv` — team information
